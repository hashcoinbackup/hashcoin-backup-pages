HashCoin Backup - Privacy Policy

Last updated: October 7, 2026

1. About This Application

HashCoin Backup is a private backup utility for the HashCoin project. It is intended to store and recover project backups using Google Drive with the account owner's authorization.

2. Google Drive Access

The application requests the Google Drive drive.file permission to create and manage files used by the application.

3. Data Processing

When backup operations are enabled, HashCoin project backup files are transferred to the authorized Google Drive account. Google OAuth credentials are used for authenticated access.

4. Data Security

The backup system is intended to use encryption before transferring backup files to cloud storage. Access credentials must be protected against unauthorized use.

5. Data Sharing

HashCoin Backup does not sell Google user data or use it for advertising. Backup information is not intentionally shared with unrelated third parties.

6. Data Retention and Deletion

Backup files may be retained according to the configured backup schedule. The account owner can delete stored files and revoke Google access through Google Account settings.

7. Contact

For privacy-related questions, contact: hashcoinbackup@gmail.com

8. Updates

This privacy policy may be updated when the backup system or its data processing practices change.
